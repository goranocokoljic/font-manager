# Font Fu brand assets

Source artwork for the logo. The app icons in `apps/desktop/src-tauri/icons/` and
`apps/desktop/src/components/AppLogo.vue` are generated from these files.

| File | Use |
| --- | --- |
| `fontfu-master-sheet.svg` | The original sheet as drawn (light, dark, icon sizes) |
| `fontfu-lockup.svg`, `fontfu-lockup-dark.svg` | Icon + wordmark, for light and dark backgrounds |
| `fontfu-lockup-flat.svg`, `fontfu-lockup-dark-flat.svg` | The same without the gradient |
| `fontfu-lockup-mono.svg` | One colour (`currentColor`) |
| `fontfu-wordmark.svg`, `fontfu-wordmark-dark.svg` | Wordmark alone |
| `fontfu-icon.svg`, `fontfu-icon-flat.svg` | Icon, 64 px and larger |
| `fontfu-icon-small.svg` | Icon with a heavier ff, 21 to 64 px |
| `fontfu-icon-tiny.svg` | Icon with the heaviest ff, 20 px and smaller |

Colours: purple `#AB4B96`, gradient end `#813971`, ink `#17151A`, paper `#FAF8F4`.

The ff is Newsreader Italic and the wordmark is Space Grotesk, both under the
SIL Open Font License. All type is converted to outlines.
