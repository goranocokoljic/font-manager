# Keyboard shortcuts

On a Mac, use `Cmd` where this page says `Ctrl`. Both keys work on every system.

## Everywhere

| Key | What it does |
|-----|--------------|
| `Ctrl+K` | Open or close the command palette |
| `/` | Go to the search box |
| `Ctrl+,` | Open the settings (also in the File menu, in the Font Manager menu on a Mac, in the tray menu and in the status bar) |

## In the font list

| Key | What it does |
|-----|--------------|
| `Up` and `Down` | Go to the previous or next row (in the grid: the card above or below) |
| `Page Up` and `Page Down` | Go up or down one screen |
| `Home` and `End` | Go to the first or last row |
| `Right` and `Left` | Show or hide the styles of a family (in the grid: go to the next or previous card) |
| `Enter` | Open the family page of the font |
| `Shift+Up` and `Shift+Down` | Add the next rows to the selection |
| `Ctrl+Space` | Add the row to the selection, or take it out |
| `Ctrl+A` | Select all fonts |
| `A` | Activate or deactivate the selected fonts for this session |
| `Shift+A` | Activate or deactivate the selected fonts permanently |
| `1` | Show the fonts as a list |
| `2` | Show the fonts as a table |
| `3` | Show the fonts as a grid of cards |
| `4` | Show the fonts as a waterfall: the preview text at six sizes |
| `5` | Show the selected font in a layout: a page of text, for example a book page |
| `Space` | Quick look: the selected font in a large preview; `Space` or `Escape` closes it |
| `C` | Pin the selected font to Compare (up to 4 fonts) |
| `B` | Add the selected fonts to the Quick Collection, or remove them if they are in it |
| `T` | Open the tagging panel for the selected fonts; with no font selected, go to the preview field (`Esc` returns to the list) |
| `S` | Find the fonts that look like the selected font |
| `O` | Open the family page of the selected font (a double-click on its row or card does the same) |

Keys without `Ctrl` do not work while you type in a text box, so you can type an "a"
in the search box.

## In the Quick Collection

| Key | What it does |
|-----|--------------|
| `Up` and `Down` | Go to the previous or next font |
| `Delete` or `Backspace` | Drop the font from the Quick Collection |

## In the tagging panel

Select fonts and press `T` (or run **Tag the selected fonts…** in the command
palette). The panel lists every tag. A tag shows **on all**, **on some** or
**on none** of the selected fonts. You can also drag fonts from the list or the
table onto a tag under **Tags** in the sidebar. A dragged family gets the tag on
all of its styles. While you drag, the sidebar marks the tags that the fonts
already have.

| Key | What it does |
|-----|--------------|
| Type a name | Show only the tags that match |
| `Up` and `Down` | Go to the previous or next tag |
| `Space` | Put the tag on all the selected fonts, or take it off all of them. Press again to undo |
| `Enter` | Apply the changes and close. If no tag has the name you typed, make that tag on the selected fonts |
| `Esc` | Close the panel without applying the changes |

## In the similar fonts

Select a font and press `S`. You can also click **Similar** on the row (point to
the row to see it), click **Find similar** on the family page, or run **Find similar
fonts** in the command palette. The panel **Similar to** opens below the font list.
It shows the fonts that look like the selected font, closest first. Each font shows
the preview text in that font, how similar it is in percent, and why.

| Key | What it does |
|-----|--------------|
| `Up` and `Down` | Go to the previous or next font |
| `Home` and `End` | Go to the first or last font |
| `Enter` | Open the family page of the font |
| `Tab` | Go to the next font, or to the close button |
| `Esc` | Close the panel |

If a search or a filter hides the font in the list, its family page still shows it.

## In the layout

In the layout view, press `Tab` to go to a block of text.

| Key | What it does |
|-----|--------------|
| `Right` and `Left` | Make the text of the block larger or smaller (with `Shift`: in bigger steps) |
| `Up` and `Down` | Add or remove space between the lines of the block (with `Shift`: in bigger steps) |
| `Enter` | Edit the text of the block that has the focus |
| `Ctrl+Enter` | Keep the edit and close the text box (`Cmd+Enter` on a Mac). A click outside the block also keeps it |
| `Esc` | Drop the edit and close the text box, or go back to the size before a drag |

## In Compare

Pin two to four fonts with `C`, then click **Compare** in the toolbar (or run
**Open Compare** in the command palette). Compare opens as a sheet from the bottom
of the window, over the fonts. Drag the bar on its top edge to make it taller or
shorter, from 40% of the window to the full window. Double-click the bar, or click
**Full height**, to fill the window; do it again to go back. Compare opens at the
height you used last. Compare shows the pinned fonts in the preview text of the
list, all at the same size. At **Auto**, the size grows with the sheet: 56 px at the
lowest height, 80 px at full height. Choose a mode: **Side by side**,
**Stacked** or **Overlay**. Overlay draws two fonts on one baseline in two colors;
with three or four pinned, choose the two fonts. **Remove** takes a font out of
Compare. The pins stay until you close the app.

To keep a comparison, type a name and click **Save comparison**. The fonts, the
mode and the preview text are saved. To open a saved comparison, click its name
under **Saved comparisons** (the bookmark button) in Compare, or run **Open comparison:** and its name in the command
palette. If a font of the comparison is no longer in the library, Compare opens
with the other fonts and tells you which font is missing.

**Pairings**, below the fonts, suggests fonts from other families that go with the
first pinned font. The rules are: a serif or slab with a sans (and the other way
round), a display or script font only with a sans or a serif, an x-height within
5%, the same designer, or the same superfamily ("Noto Sans" and "Noto Serif").
Each suggestion shows how well it matches and why. **Add to compare** pins it.

| Key | What it does |
|-----|--------------|
| `Left` and `Right` | Change the mode, when the focus is on the mode |
| `Tab` | Go to the next control in Compare |
| `Up` and `Down` | Make Compare taller or shorter, when the focus is on its top bar |
| `Home` and `End` | Make Compare its lowest height or the full window, when the focus is on its top bar |
| `Esc` | Close the saved comparisons list; else close Compare and go back to the list |

## The command palette

Press `Ctrl+K` and type a few letters of a command, for example "act" for the
activation commands. Use `Up` and `Down` to choose and `Enter` to run it. `Esc`
closes the palette. Each command shows its key, if it has one.

The **Help** commands in the palette open these pages, like the **Help** menu does.

## Moving between the parts of the window

Press `Tab` to go from the sidebar to the font list. On the family page, `Tab` moves
between the sections and their controls, and `Left` and `Right` go to the previous or
next family. `Esc` goes back to the list. On a feature switch, `Space` turns the feature on or off.
In the glyph grid, the arrow keys move from character to character, `Home` and `End`
go to the first and the last character, and `Enter` selects the character.
Letter and number keys also work on keyboards for other alphabets, for example
Cyrillic or Greek.
